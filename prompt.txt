GOAL

- No Docker required

DESIGN CHANGE (this is the important product change)
Bad current UX: pick ONE website to scrape a series from.
Correct UX: a series can have MANY sources. The downloader should get the missing chapter from whichever source works.

Rules:
1. One logical manga, many MangaConnectorIds.
2. If a series is monitored, refresh chapter lists from ALL attached sources, not only the originally chosen one.
3. For each undownloaded Chapter, queue ONE download job.
4. Pick the best available source for that chapter:
   preference: MangaDex > AsuraComic > Mangaworld > WeebCentral > other
5. If a source fails (403, Cloudflare, empty image list, timeout), cool it down with exponential backoff (30 min base, max 6 hours). Do not retry that chapter/source every minute.
6. If another source has the same chapter, use that instead.
7. Never mark a failed download as Completed/success.
