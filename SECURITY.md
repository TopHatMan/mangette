# Security

Mangette is a **local / LAN** app. Do not put port 8585 or FlareSolverr (8191) on the public internet. FlareSolverr has no login.

Report vulnerabilities privately to the repo owner via GitHub Security Advisories on [TopHatMan/mangette](https://github.com/TopHatMan/mangette). Do not file a public issue for a remote-code or auth bypass.
